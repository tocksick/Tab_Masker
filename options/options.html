Noch nicht geprüft.

    Neuer Code liegt auf GitHub, wird aber aus Sicherheitsgründen von Chrome nicht automatisch installiert (Erweiterungen im Entwicklermodus dürfen sich nicht selbst aktualisieren). So holst du die Änderungen manuell:

    1. Aktuelle Version von GitHub herunterladen (grüner „Code"-Button → „Download ZIP") und den alten Ordner damit ersetzen. Nutzt du Git? Dann reicht git pull.
    2. Unten auf „Erweiterungsseite öffnen" klicken.
    3. Dort bei Tab Masker auf das 🔄-Symbol klicken, damit Chrome die neuen Dateien lädt.

    Ist die Maskierung deaktiviert, zeigen alle Tabs wieder ihren echten Titel und ihr echtes Favicon.

    Domain zur Maskierung hinzufügen

    Nur Domains in dieser Liste werden maskiert. Trage eine Domain ein (z. B. example.com), um sie mit einem zufälligen Namen/Icon zu versehen.

    Ohne Vorlage bekommt die Domain automatisch einen zufälligen, aber realistischen Tarnnamen (z. B. „Outlook“ oder „Google Docs“) inklusive passender, umgefärbter Logo-Form. Mit Vorlage legst du stattdessen gezielt einen bestimmten Tarnnamen fest.

    Maskierte Domains

    Alle Domains, die aktuell auf der Maskierungsliste stehen. Domains, die hier nicht auftauchen, werden nicht maskiert.
